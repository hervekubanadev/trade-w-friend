# Changelog

## [1.0.0] — 2026-06-30

### Added

- Initial release of TradeWFriend kiosk POS system
- Phone + 6-digit PIN authentication via SHA-256 hashing
- Full-screen kiosk mode with immersive sticky UI and admin PIN lock
- Inventory management with CRUD operations and stock status tracking
- Sales recording with real-time profit calculation
- Customer management and debt tracking with payment recording
- 7-day sales reports with bar chart visualizations (fl_chart)
- Dark/light theme support with system preference detection
- Business profile settings with factory reset capability
- GoRouter declarative routing with auth guards and kiosk interceptor
- Riverpod state management with Feature-first clean architecture
- Supabase PostgreSQL backend with Row-Level Security
- Multi-platform support: Android, iOS, Web, Linux, macOS, Windows
